## 🏗️ Gerçek Şantiye Fotoğrafları Entegrasyonu
Proje dosyasındaki `resimler/` klasöründe yer alan 6 adet gerçek şantiye ve inşaat fotoğrafı optimize edilerek web sitesinde interaktif filtreli şantiye vitrini ve lightbox detay modalları olarak entegre edilmiştir:

1. **Canikoğlu Park Konutları:** Çok bloklu kentsel dönüşüm sitesi, kule vinç ve tünel kalıp inşaatı (`proje-1-konut-bloklari.jpg`).
2. **Marmara Vizyon Blokları:** Ada bazlı kentsel dönüşüm, ağır iş makineleri ve C35/40 radye temel kaba yapı şantiyesi (`proje-2-santiye-kaba-yapi.jpg`).
3. **Modern Şehir Konutları:** Bakırköy lüks rezidans, dış cephe iskele, A1 taşyünü mantolama ve ince işçilik (`proje-3-cephe-ve-ince-isler.jpg`).
4. **Endüstriyel Çelik & Yangın Merdiveni:** Gebze OSB, 45 ton sıcak daldırma galvaniz çelik yangın merdiveni ve taşıyıcı konstrüksiyon (`proje-4-celik-konstruksiyon.jpg`).
5. **Spor & Yaşam Kompleksi:** Başakşehir 12.500 kişilik prekast betonarme tribün ve 72 metre çelik uzay çatı sistemi (`proje-5-tribun-stadyum-yapi.jpg`).

## 🚀 Çalıştırma & Yayına Alma
1. **Doğrudan Tarayıcıda Açma:**
   - `index.html` dosyasına çift tıklayarak herhangi bir tarayıcıda (Chrome, Edge, Firefox, Safari) doğrudan görüntüleyebilirsiniz.
2. **Yerel Sunucu ile Çalıştırma:**
   - PowerShell / Terminal üzerinden:
     ```bash
     python -m http.server 8000
     ```
     veya Node.js ile:
     ```bash
     npx serve
     ```
   - Tarayıcınızda `http://localhost:8000` adresine gidin.
3. **Canlı Hosting (cPanel / Apache / Vercel / Netlify):**
   - Tüm proje dosyalarını doğrudan cPanel `public_html` klasörüne veya Vercel/Netlify üzerine yükleyebilirsiniz. Ekstra derleme (build) gerektirmez.
